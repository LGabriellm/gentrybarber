# Design system

Consultar [DESIGN_SYSTEM.md](../../../docs/DESIGN_SYSTEM.md). Separar variante visual de regra comercial. Tokens do tenant são dados validados, com catálogo de fontes e faixas permitidas.

Preservar semântica, foco visível, teclado, contraste e responsividade. Animação respeita reduced motion e não bloqueia leitura ou ação. CSS de tema não alcança painel/admin.

Preferir composições e variantes existentes; acrescentar componente quando há necessidade observável. Validar textos longos, imagens ausentes e duas instâncias com tokens diferentes. Medir performance antes de declarar metas cumpridas.
